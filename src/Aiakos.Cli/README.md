# Aiakos

**Early preview placeholder. Not yet functional.**

Aiakos is a file-defined control plane for teams of AI coding agents, built in .NET. This
package reserves the `aiakos` .NET tool. It currently only prints a greeting and its version.
The real CLI (`up`, `down`, `send`, `capture`, `ps`) arrives with milestone M1.

```bash
dotnet tool install -g Aiakos --prerelease
aiakos            # prints a greeting and the version
aiakos --version  # prints the version only
```
