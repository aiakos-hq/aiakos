# Protos

The orchestrator ↔ node contract: [`aiakos/node/v1/node_link.proto`](aiakos/node/v1/node_link.proto),
package `aiakos.node.v1`, one bidirectional RPC `NodeLinkService.Connect`. It is defined by
[spec 0002](../../../docs/specs/0002-orchestrator-node-grpc-contract.md) (#10); change the spec
and the file together.

C# is generated by `Grpc.Tools` during `dotnet build` (namespace `Aiakos.Contracts.Node.V1`);
no generated code is committed.

Within `v1` every change is additive. CI checks that with [buf](https://buf.build) **1.73.0**
(configuration in [`buf.yaml`](../../../buf.yaml) at the repository root). To run the checks
locally, install that version and run from the repository root:

```sh
buf lint
buf breaking --against '.git#branch=main'
```
