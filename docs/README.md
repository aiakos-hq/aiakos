# Aiakos documentation

This folder is the source of the documentation published at [aiakos.dev/docs](https://aiakos.dev/docs).
It changes in the same pull request as the code it describes.

| Section | Contents |
|---|---|
| [`plan.md`](plan.md) | Architecture, technology decisions, roadmap, how we build it |
| [`adr/`](adr/) | Architecture Decision Records — decisions already made |
| [`specs/`](specs/) | Specs for features: requirements, design, acceptance criteria, test plan |
| [`spikes/`](spikes/) | Findings from throwaway experiments |
| [`risks.md`](risks.md) | Risk register: index of open risks from specs and spikes, with how and when to check them |
| [`workflow.md`](workflow.md) | How an issue becomes merged code in stage A: briefs, stories, the definitions of ready and done |
| [`briefs/`](briefs/) | The briefs of the M1 slices and their split into stories |

User-facing guides (getting started, rig file reference, CLI reference) will be added from M1.
